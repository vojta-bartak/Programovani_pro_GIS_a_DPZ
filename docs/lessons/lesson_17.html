Lekce 17: Geometrie I - struktura geometrií

Python pro GIS - Čtení a zápis objektů Geometry

Author

Vojtěch Barták, FŽP ČZU Praha

Published

December 10, 2025

1 Úvod

V předchozích lekcích jsme pracovali s atributovými daty v tabulkách. Nyní se zaměříme na geometrickou složku geoprvků - na objekty reprezentující prostorové tvary jako body, linie a polygony.

Po absolvování lekce budete umět:

  • Porozumět hierarchické struktuře geometrických objektů v arcpy
  • Číst souřadnice bodů, lomových bodů linií a vrcholů polygonů
  • Pracovat s jednoduchými i vícedílnými (multipart) geometriemi
  • Vytvářet nové geometrické objekty programově
  • Vkládat vytvořené geometrie do feature class pomocí kurzorů
NoteProč pracovat s geometriemi přímo?

Přímá práce s geometriemi umožňuje:

  • Vytvářet nové geoprvky programově (bez ručního digitalizování)
  • Analyzovat a upravovat existující geometrie
  • Importovat prostorová data z nestandardních formátů
  • Provádět vlastní geometrické výpočty a transformace

1.1 Data

V lekci budeme pracovat s následujícími daty:

  • Bodová vrstva měst Sidla_body.shp z datasetu Kraje_sidla
  • Liniová vrstva silnic (můžete použít vlastní data nebo stáhnout testovací data)
  • Polygonová vrstva krajů Kraje.shp z datasetu Kraje_sidla

2 Struktura geometrických objektů

Geometrie v arcpy mají hierarchickou strukturu postavenou na několika základních třídách:

  1. arcpy.Point - reprezentuje jeden bod (vertex) se souřadnicemi X, Y (a volitelně Z, M)
  2. arcpy.Array - kolekce bodů nebo kolekcí bodů (posloupnost)
  3. arcpy.Geometry - základní třída pro všechny geometrie
    • arcpy.PointGeometry - bodová geometrie
    • arcpy.Multipoint - multipart bodová geometrie
    • arcpy.Polyline - liniová geometrie
    • arcpy.Polygon - polygonová geometrie
TipAnalogie se strukturou dat

Můžete si to představit jako:

  • Point = jednotlivé číslo
  • Array = seznam čísel
  • Geometry = komplexní struktura (objekt) obsahující seznamy čísel s dalšími vlastnostmi

2.1 Bodové geometrie

Bodové geometrie (PointGeometry) jsou na první pohled nejjednodušší typ geometrie. Každý bodový geoprvek obvykle obsahuje jeden objekt Point se souřadnicemi X a Y. Existují však i multipart bodové geometrie, které obsahují více oddělených bodů v rámci jednoho záznamu v atributové tabulce.

2.1.1 Struktura jednoduché bodové geometrie

U běžných (single-part) bodových geometrií je struktura přímočará. Když z kurzoru načteme pole SHAPE@, získáme objekt PointGeometry. Z něj pak můžeme extrahovat samotný bod pomocí vlastnosti firstPoint, která vrací objekt Point s konkrétními souřadnicemi.

import arcpy
arcpy.env.workspace = r"C:\my_path\..."

with arcpy.da.SearchCursor("Sidla_body.shp", ["SHAPE@", "NAZEV"]) as cursor:
    for row in cursor:
        point_geom = row[0]  # Objekt PointGeometry
        point = point_geom.firstPoint  # Objekt Point
        
        # Výpis souřadnic
        print(f"{row[1]}: X={point.X:.2f}, Y={point.Y:.2f}")

V této ukázce vidíme základní postup: načteme celou geometrii (row[0]), což je objekt PointGeometry, a z něj pak získáme konkrétní bod (firstPoint). Ten má vlastnosti X a Y s konkrétními souřadnicemi.

2.1.2 Různé způsoby přístupu k souřadnicím

ArcPy poskytuje několik zkratek pro přístup k souřadnicím bodů, které jsou v mnoha situacích pohodlnější než cesta přes firstPoint. Tyto zkratky se používají přímo při specifikaci polí v kurzoru.

with arcpy.da.SearchCursor("Sidla_body.shp", ["SHAPE@", "SHAPE@XY", "SHAPE@X", "SHAPE@Y", "NAZEV"]) as cursor:
    for row in cursor:
        # Způsob 1: Přes objekt Geometry a Point
        geom = row[0]
        point = geom.firstPoint
        x1, y1 = point.X, point.Y
        
        # Způsob 2: Přes SHAPE@XY (vrací tuple)
        x2, y2 = row[1]
        
        # Způsob 3: Přes SHAPE@X a SHAPE@Y
        x3, y3 = row[2], row[3]
        
        print(f"{row[4]}: ({x1}, {y1})")

Tento příklad demonstruje tři ekvivalentní způsoby, jak získat souřadnice téhož bodu. První způsob (SHAPE@ + firstPoint) dává nejplnější přístup k objektu Point, druhý způsob (SHAPE@XY) vrací přímo tuple se souřadnicemi, třetí způsob (SHAPE@X a SHAPE@Y) vrací jednotlivé souřadnice jako samostatné hodnoty.

TipKterý způsob použít?
  • SHAPE@XY - nejrychlejší a nejčastější volba, vrací tuple (x, y)
  • SHAPE@X a SHAPE@Y - když potřebujete jen jednu souřadnici nebo když píšete kód, kde je jasné, že pracujete odděleně s X a Y
  • SHAPE@ + firstPoint - když potřebujete plný přístup k objektu Point (např. pro Z či M souřadnice, nebo pro práci s multipart geometriemi)

2.1.3 Vlastnosti objektu Point

Objekt Point uchovává nejen povinné souřadnice X a Y, ale může obsahovat i další informace. U 3D dat to je souřadnice Z (nadmořská výška nebo jiná vertikální dimenze), u lineárně referenčních dat může být přítomna hodnota M (měřená vzdálenost podél linie). Pokud tyto dimenze nejsou použity, příslušné vlastnosti mají hodnotu None.

with arcpy.da.SearchCursor("Sidla_body.shp", ["SHAPE@"]) as cursor:
    row = cursor.next()
    point = row[0].firstPoint
    
    print(f"X: {point.X}")
    print(f"Y: {point.Y}")
    print(f"Z: {point.Z}")  # None pokud není 3D
    print(f"M: {point.M}")  # None pokud není M hodnota
    print(f"ID: {point.ID}")

V tomto příkladu používáme metodu cursor.next() k načtení pouze prvního záznamu, což je užitečné, když chceme prozkoumat strukturu dat bez procházení všech záznamů. Vlastnosti Z a M budou mít hodnotu None, pokud data nejsou trojrozměrná nebo neobsahují měřené hodnoty.

2.1.4 Multipart bodové geometrie

Ne všechny bodové geometrie obsahují jen jeden bod. Občas se setkáme s multipart bodovými geometriemi, kde jeden záznam v atributové tabulce reprezentuje více oddělených bodů. Typickým příkladem může být měřená lokalita s více měřícími body, které logicky patří k jednomu objektu. Multipart bodová geometrie je reprezentována objektem Multipoint.

U multipart geometrií už nestačí firstPoint - potřebujeme procházet všechny části geometrie. Objekt Multipoint je k tomu účelu uzpůsoben, lze jej totiž procázet v cyklu přes jednotlivé body.

with arcpy.da.SearchCursor("Sidla_body.shp", ["SHAPE@", "NAZEV"]) as cursor:
    for row in cursor:
        point_geom = row[0]
        
        if point_geom.isMultipart:
            print(f"Počet bodů: {point_geom.pointCount}")
            
            # Procházení všech bodů multipart prvku
            for point in point_geom:
                print(f"  Bod: ({point.X:.2f}, {point.Y:.2f})")

Zde vidíme klíčový moment: když procházíme geometrii cyklem (for point in point_geom), získáváme objekty Point, které obsahují jednotlivé body.

2.1.5 Zjištění typu geometrie

Někdy potřebujeme zjistit, zda je geometrie multipart, aniž bychom procházeli všechny její části. K tomu slouží vlastnost isMultipart a vlastnost partCount, která říká počet částí geometrie.

with arcpy.da.SearchCursor("Sidla_body.shp", ["SHAPE@", "NAZEV"]) as cursor:
    for row in cursor:
        geom = row[0]
        
        print(f"{row[1]}:")
        print(f"  Je multipart: {geom.isMultipart}")
        print(f"  Počet částí: {geom.partCount}")
        print(f"  Počet bodů celkem: {geom.pointCount}")
        print(f"  Typ: {geom.type}")

Vlastnost type vrací textový řetězec identifikující typ geometrie - pro bodové geometrie to bude "point", pro multipart body "multipoint". To je užitečné, když pracujeme s různými typy geometrií ve stejném kódu a potřebujeme rozlišit, s čím aktuálně pracujeme.

2.2 Liniové geometrie

Linie (Polyline) jsou složitější než body. Skládají se z posloupnosti bodů (lomových bodů), které dohromady tvoří čáru. Každý lomový bod je objekt Point a celá posloupnost je uložena v objektu Array. Linie tak využívá hierarchii Point → Array → Polyline.

2.2.1 Struktura liniové geometrie

Když z kurzoru načteme liniovou geometrii, získáme objekt Polyline, který má řadu užitečných vlastností. Kromě samotné posloupnosti bodů můžeme přímo zjistit délku linie, počet částí (pokud jde o multipart feature) a celkový počet lomových bodů.

with arcpy.da.SearchCursor("Silnice.shp", ["SHAPE@"]) as cursor:
    row = next(cursor)
    line = row[0]
    
    # Základní vlastnosti linie
    print(f"Délka: {line.length:.2f} m")
    print(f"Počet částí: {line.partCount}")
    print(f"Počet bodů: {line.pointCount}")

Tyto vlastnosti jsou velmi užitečné pro rychlou analýzu dat bez nutnosti procházet všechny body manuálně. Délka je vypočítána v jednotkách souřadnicového systému dat (typicky metry u projektovaných souřadnicových systémů).

2.2.2 Čtení lomových bodů linie

Pro detailní práci s linií potřebujeme přístup k jednotlivým lomovým bodům. Linii procházíme dvěma vnořenými cykly: vnější cyklus prochází části (parts) linie, vnitřní cyklus prochází body v každé části. U jednoduchých linií (single-part) bude vnější cyklus proveden pouze jednou.

with arcpy.da.SearchCursor("Silnice.shp", ["SHAPE@", "NAZEV"]) as cursor:
    for row in cursor:
        line = row[0]
        print(f"\nLinie: {row[1]}")
        
        # Procházení všech částí linie
        for part in line:

            # Procházení bodů v části
            for point in part:
                print(f"{point.X:.2f}, {point.Y:.2f}")
NoteCo jsou části (parts)?

Jedna feature může obsahovat více oddělených částí. Například dálnice D1 může být rozdělena na několik úseků (parts), které spolu fyzicky nesousedí. Každá část je samostatná linie s vlastní posloupností bodů. V atributové tabulce to zůstává jediným záznamem, ale geometricky jde o více oddělených linií.

2.2.3 Zjištění počtu lomových bodů

Pokud nás zajímá pouze celkový počet lomových bodů bez potřeby je všechny procházet, můžeme použít vlastnost pointCount. Někdy ale potřebujeme spočítat body manuálně, například když filtrujeme určité body nebo když pracujeme s multipart features a chceme znát počty bodů v jednotlivých částech.

with arcpy.da.SearchCursor("Silnice.shp", ["SHAPE@", "NAZEV"]) as cursor:
    for row in cursor:
        line = row[0]
        total_points = 0
        
        for part in line:
            part_points = len([p for p in part])
            total_points += part_points
            
        print(f"{row[1]}: {total_points} lomových bodů")

List comprehension [p for p in part] vytváří seznam všech nenulových bodů v části. Funkce len() pak spočítá prvky tohoto seznamu.

2.2.4 Extrakce prvního a posledního bodu

Pro některé analýzy potřebujeme znát pouze koncové body linie - například když testujeme konektivitu sítě nebo když hledáme, kde linie začíná a končí. ArcPy poskytuje vlastnosti firstPoint a lastPoint, které vrací tyto krajní body přímo, bez nutnosti procházet všechny lomové body.

with arcpy.da.SearchCursor("Silnice.shp", ["SHAPE@"]) as cursor:
    for row in cursor:
        line = row[0]
        
        # První a poslední bod celé linie
        first_point = line.firstPoint
        last_point = line.lastPoint
        
        print(f"Začátek: ({first_point.X:.2f}, {first_point.Y:.2f})")
        print(f"Konec: ({last_point.X:.2f}, {last_point.Y:.2f})")

U multipart linií tyto vlastnosti vrací první bod první části a poslední bod poslední části. Pokud potřebujete koncové body každé části zvlášť, musíte procházet části cyklem a pro každou část extrahovat její první a poslední prvek.

2.3 Polygonové geometrie

Polygony (Polygon) jsou nejsložitější geometrický typ. Podobně jako linie se skládají z posloupnosti bodů, ale tyto body tvoří uzavřený tvar - první a poslední bod jsou stejné. Navíc polygony mohou mít vnitřní hranice (díry, holes), což vytváří další úroveň složitosti ve struktuře dat.

2.3.1 Struktura polygonové geometrie

Objekt Polygon poskytuje přímý přístup k základním metrickým vlastnostem. Kromě obvodu (který je analogický k délce linie) máme k dispozici i plochu. Stejně jako u linií můžeme zjistit počet částí a celkový počet vrcholů.

with arcpy.da.SearchCursor("Kraje.shp", ["SHAPE@", "NAZEV"]) as cursor:
    row = next(cursor)
    polygon = row[0]
    
    # Základní vlastnosti polygonu
    print(f"Plocha: {polygon.area:.2f} m²")
    print(f"Obvod: {polygon.length:.2f} m")
    print(f"Počet částí: {polygon.partCount}")
    print(f"Počet bodů: {polygon.pointCount}")

Plocha je vypočítána v jednotkách odpovídajících kvadrátu jednotky souřadnicového systému (obvykle m²). Vlastnost length u polygonů představuje obvod - součet délek všech hran včetně případných vnitřních hranic.

2.3.2 Čtení vrcholů polygonu

Procházení vrcholů polygonu je podobné jako u linií, ale s důležitým rozdílem: posloupnost bodů může obsahovat hodnoty None, které signalizují přechod od vnější hranice k vnitřní hranici (díře). První posloupnost bodů vždy definuje vnější hranici polygonu, po None následuje posloupnost definující první vnitřní hranici, po další None druhou vnitřní hranici, atd.

with arcpy.da.SearchCursor("Kraje.shp", ["SHAPE@", "NAZEV"]) as cursor:
    for row in cursor:
        polygon = row[0]
        print(f"\nPolygon: {row[1]}")
        
        # Procházení všech částí polygonu
        for part_num, part in enumerate(polygon):
            print(f"  Část {part_num}:")
            
            # Sledování, zda jsme ve vnější nebo vnitřní hranici
            is_exterior = True
            for point in part:
                if point:
                    if is_exterior:
                        print(f"    Vnější hranice: ({point.X:.2f}, {point.Y:.2f})")
                    else:
                        print(f"    Vnitřní hranice: ({point.X:.2f}, {point.Y:.2f})")
                else:
                    # None signalizuje přechod na vnitřní ring
                    print(f"    --- Vnitřní ring ---")
                    is_exterior = False

V tomto kódu sledujeme pomocí proměnné is_exterior, zda právě procházíme vnější či vnitřní hranici. Potkáme-li hodnotu None, přepneme flag na False a víme, že následující body patří k díře v polygonu.

NoteVnitřní ringy (díry v polygonech)

Polygon může obsahovat díry - například jezero uprostřed kraje nebo park uprostřed zastavěného území. Tyto díry jsou reprezentovány jako vnitřní ringy. V posloupnosti bodů je vnitřní ring oddělen hodnotou None.

Struktura tedy vypadá takto: - Vnější hranice: posloupnost bodů definující obrys polygonu - None - odděluje vnější a vnitřní hranici - Vnitřní hranice: posloupnost bodů definující díru v polygonu - Případně další None a další vnitřní hranice…

Vnitřní ringy jsou orientovány opačně než vnější hranice - pokud vnější hranice běží proti směru hodinových ručiček, vnitřní ringy běží po směru hodinových ručiček (nebo naopak).

2.3.3 Multipart polygony

Multipart polygonové geometrie obsahují více oddělených polygonů v rámci jednoho záznamu. To je užitečné například pro reprezentaci ostrůvků patřících k jednomu státu nebo pro parcely, které jsou fyzicky oddělené, ale administrativně tvoří celek.

with arcpy.da.SearchCursor("Kraje.shp", ["SHAPE@", "NAZEV"]) as cursor:
    for row in cursor:
        polygon = row[0]
        
        if polygon.isMultipart:
            print(f"{row[1]} je multipart polygon s {polygon.partCount} částmi")
            
            for part_num, part in enumerate(polygon):
                print(f"  Část {part_num}")
        else:
            print(f"{row[1]} je jednoduchý polygon")

Každá část multipart polygonu může sama obsahovat vnitřní ringy. Struktura tak může být: Část 1 (vnější + díry) → Část 2 (vnější + díry) → … Všechny tyto části stále patří k jednomu záznamu v atributové tabulce.

2.3.4 Centroid a extent

Pro mnoho analýz nepotřebujeme znát všechny vrcholy polygonu, ale postačí nám některé odvozené vlastnosti. Centroid (těžiště) je bod reprezentující “střed” polygonu, extent (ohraničující obdélník) definuje minimální a maximální souřadnice X a Y polygonu.

with arcpy.da.SearchCursor("Kraje.shp", ["SHAPE@", "NAZEV"]) as cursor:
    for row in cursor:
        polygon = row[0]
        
        # Centroid (těžiště) polygonu
        centroid = polygon.centroid
        print(f"{row[1]} - centroid: ({centroid.X:.2f}, {centroid.Y:.2f})")
        
        # Ohraničující obdélník (extent)
        extent = polygon.extent
        print(f"  Extent: {extent.XMin:.2f}, {extent.YMin:.2f}, {extent.XMax:.2f}, {extent.YMax:.2f}")

Centroid je užitečný například pro umístění popisků na mapě nebo pro výpočet vzdáleností mezi polygony. Extent se často používá pro rychlé prostorové dotazy - dvě feature se nemohou překrývat, pokud se jejich extenty nepřekrývají, což je mnohem rychlejší test než detailní geometrická analýza.

4.5.2 Vytvoření pravidelného mnohoúhelníku

import math

def create_regular_polygon(center_x, center_y, radius, num_vertices):
    """Vytvoří pravidelný mnohoúhelník"""
    body = []
    
    for i in range(num_vertices + 1):  # +1 pro uzavření
        angle = 2 * math.pi * i / num_vertices
        x = center_x + radius * math.cos(angle)
        y = center_y + radius * math.sin(angle)
        body.append(arcpy.Point(x, y))
    
    array = arcpy.Array(body)
    return arcpy.Polygon(array)

# Použití

def create_grid_cell(x_min, y_min, cell_size):
    """Vytvoří jeden čtvercový polygon"""
    body = [
        arcpy.Point(x_min, y_min),
        arcpy.Point(x_min + cell_size, y_min),
        arcpy.Point(x_min + cell_size, y_min + cell_size),
        arcpy.Point(x_min, y_min + cell_size),
        arcpy.Point(x_min, y_min)
    ]
    return arcpy.Polygon(arcpy.Array(body))

def is_closed(polygon):
    """Zkontroluje, zda je polygon uzavřený"""
    for part in polygon:
        points = [p for p in part if p is not None]
        if len(points) < 3:
            return False
        
        first = points[0]
        last = points[-1]
        
        if first.X != last.X or first.Y != last.Y:
            return False
    
    return True

with arcpy.da.SearchCursor("Polygony.shp", ["SHAPE@", "OID@"]) as cursor:
    for row in cursor:
        if not is_closed(row[0]):
            print(f"Neuzavřený polygon: záznam {row[1]}")
